# PQlocalAgentOSv3

Локальная платформа управления AI-системами.

## Запуск в Windows

1. Установите Python 3.10+.
2. Запустите `start.bat`.
3. Откройте http://127.0.0.1:8765.

## Возможности
- Единый frontend-шаблон.
- Настройки внешнего вида с сохранением на диск.
- Создание, редактирование и удаление страниц из интерфейса.
- Backend API на Python без внешних зависимостей.
- GitHub-интеграция через backend и `GITHUB_TOKEN`.
- Журнал операций и проверка состояния.

Сервер привязан к `127.0.0.1`. Старый проект можно запускать отдельно на другом порте. Токен GitHub нельзя помещать во frontend-код.
