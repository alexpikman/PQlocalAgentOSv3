# PQlocalAgentOSv3

Локальная платформа управления AI-системами.

## Запуск в Windows

1. Установите Python 3.10+.
2. Для подключения GitHub (необязательно) откройте PowerShell и выполните `$env:GITHUB_TOKEN="ваш_токен"` в том же окне, откуда будете запускать сервер. Нужны права Contents: Read and write.
3. Запустите `start.bat`.
4. Откройте http://127.0.0.1:8765.

## Возможности
- Единый frontend-шаблон.
- Настройки внешнего вида с сохранением на диск.
- Создание, редактирование и удаление страниц из интерфейса.
- Backend API на Python без внешних зависимостей.
- GitHub-интеграция через backend и `GITHUB_TOKEN`: проверка подключения, список файлов, просмотр и сохранение существующих файлов коммитом.
- Журнал операций и проверка состояния.

Сервер привязан к `127.0.0.1`. Старый проект можно запускать отдельно на другом порте. Токен GitHub нельзя помещать во frontend-код или коммитить в репозиторий. Если токен не задан, локальные страницы и настройки всё равно работают.
