# One Core AI v1

Автономное локальное AI-приложение для Windows. Не использует сервер, backend, зависимости или запуск PQlocalAgentOSv3.

## Запуск
1. Установи Python 3.12 или новее.
2. Запусти start.bat. При первом старте создаётся отдельная среда .venv.
3. Открой http://127.0.0.1:9001.
4. В настройках выбери Ollama или LM Studio, проверь подключение и модель.

## Провайдеры
- Ollama: http://127.0.0.1:11434
- LM Studio: http://127.0.0.1:1234/v1

## Локальные данные
- config/settings.json — настройки провайдера.
- data/conversations.json — история чатов.
- logs/ — журналы (резерв).
- .venv/ — независимое Python-окружение.

Локальные настройки и история исключены из Git.

## Остановка
Запусти stop.bat или нажми Ctrl+C в окне сервера.

## Архитектура
Python stdlib ThreadingHTTPServer, только 127.0.0.1:9001; Vanilla HTML/CSS/JS; SSE streaming; Ollama API и OpenAI-compatible API LM Studio. Метрики выводятся только если их передал провайдер.

Первая версия включает чат, выбор модели, сохранение истории и монитор реальных метрик. Файловые операции, shell, SSH и автономные цепочки задач будут добавлены после проверки основы.
