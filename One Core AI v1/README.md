# One Core AI v1

Автономная локальная AI Workstation для Windows. Не использует web-сервер или runtime центрального проекта. Адрес: http://127.0.0.1:9001.

## Запуск
Запусти start.bat. Создаётся отдельная .venv. При первом запуске скачивается локальная переменная версия шрифта Manrope и лицензия SIL OFL 1.1.

## Возможности этой сборки
- Ollama и LM Studio: выбор провайдера, список моделей, загрузка/удаление моделей Ollama, запуск Ollama runtime.
- Отдельный центр настроек ИИ: системная инструкция, роль, подробность, язык, глубина анализа, планирование, память, подтверждение инструментов.
- Глобальная типографика Manrope, размер и цвет текста.
- Подключение рабочей папки и текстовые вложения в чате (до 500 КБ на файл).
- PowerShell с обязательным подтверждением каждой команды и записью в журнал.
- GitHub CLI: проверка авторизации; ограниченные команды через API.
- SSH-профили OpenSSH с ключами/ssh-agent; пароль и приватный ключ не копируются в настройки.
- Виртуальный браузер через дополнительный Playwright + Chromium.
- Журнал операций JSONL, каталог инструментов и собственные plugin manifests.

## Виртуальный браузер (необязательно)
Выполни из этой папки:
.venv\Scripts\python.exe -m pip install -r requirements-browser.txt
.venv\Scripts\python.exe -m playwright install chromium

## Ограничения и безопасность
Backend привязан к 127.0.0.1:9001. PowerShell, SSH и GitHub CLI требуют явного подтверждения. SSH хранит только имя профиля, host, user и путь к ключу; используй Windows OpenSSH agent. GitHub авторизацию хранит gh CLI. Произвольный код сторонних плагинов не исполняется: сейчас создаются и включаются только манифесты. AI-чат пока не запускает инструменты автономно — текущая библиотека является основой для следующего слоя Agent Runtime.

Данные пользователя остаются локально: config/settings.json, data/conversations.json, data/operations.jsonl. Они исключены из Git.
