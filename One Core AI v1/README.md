# One Core AI v1

Автономная локальная AI Workstation для Windows. Не использует web-сервер или runtime центрального проекта. Адрес: http://127.0.0.1:9001.

## Запуск
Запусти start.bat. Создаётся отдельная .venv. При первом запуске скачивается локальный variable font Manrope и лицензия SIL OFL 1.1. Шрифт применяется в главном окне и центре настроек.

## Возможности
- Ollama и LM Studio: выбор провайдера и списка моделей.
- Ollama: загрузка/удаление моделей, запуск локального сервера, загрузка/выгрузка модели из памяти.
- Центр настроек ИИ: роль, системная инструкция, стиль ответов, язык, глубина анализа, планирование, память, лимит шагов.
- Sampling-параметры: temperature, top_p, top_k, min_p, num_ctx, num_predict, repeat_penalty, repeat_last_n, num_thread, num_gpu, seed, mirostat.
- Manrope Variable по всему приложению, глобальный размер шрифта и цвет основного текста.
- Подключение рабочей папки. При включённом контексте в запрос добавляются ограниченные текстовые файлы проекта; скрытые, служебные и потенциально секретные файлы пропускаются.
- Текстовые вложения в чате (до 500 КБ на файл).
- PowerShell-консоль с обязательным подтверждением каждой команды и историей.
- Git и GitHub CLI: status/diff/log/pull текущей рабочей папки, авторизация GitHub CLI, список репозиториев, issues и pull requests.
- SSH-профили OpenSSH с ключами/ssh-agent и подтверждением удалённой команды.
- Виртуальный браузер на Playwright + Chromium. Ollama-модели, поддерживающие tool calling, могут искать и открывать страницы; снимок браузера обновляется в Live Monitor.
- Журнал операций JSONL, библиотека включаемых/отключаемых инструментов и собственные plugin manifests.

## Виртуальный браузер
Запусти install-browser.bat один раз. Скрипт установит Playwright и Chromium в отдельную .venv. После установки перезапусти приложение. Без этого браузерная автоматизация недоступна.

## Безопасность и текущие границы
Backend привязан к 127.0.0.1:9001. PowerShell, SSH, Git и GitHub CLI требуют явного подтверждения. SSH хранит только имя профиля, host, user и путь к ключу; пароли и приватные ключи не копируются в настройки. Используй Windows OpenSSH agent. GitHub авторизацию хранит gh CLI. Конфигурация приложения не сохраняет GitHub-токен.

Ollama tool-calling сейчас подключает к модели инструменты браузера и веб-поиска. LM Studio использует потоковый чат без tool loop. PowerShell, SSH и GitHub доступны через отдельные пользовательские панели с подтверждением, но пока не вызываются моделью автономно.

Плагины сейчас представляют собой декларативные манифесты с описанием разрешений. Произвольный код сторонних плагинов не исполняется и не скачивается автоматически. Это намеренная граница безопасности до реализации изолированного plugin runner.

Файловый контекст ограничен 25 текстовыми файлами и 70 000 символов на запрос. Вложения — текстовые файлы до 500 КБ. Выбор рабочей папки производится через ввод полного локального пути в настройках.

Данные пользователя остаются локально: config/settings.json, data/conversations.json, data/operations.jsonl. Они исключены из Git.
